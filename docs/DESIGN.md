# v1.1 设计说明

应用 GitHub [anthropics/skills 的 frontend-design](https://github.com/anthropics/skills/tree/main/skills/frontend-design)。技能安装在开发机，不作为运行依赖分发。

面向日常处理地块、路网与矢量格式的工作人员，重点是工具辨识、工作状态和清晰的数据输入输出。

色彩：导航蓝 #16324F，操作蓝 #245BD8，工作区 #F2F5FA，纸白 #FFFFFF，正文 #24364B，辅助文字 #60748A。中文使用本机微软雅黑，数字使用 Segoe UI；不加载在线字体。标题 25–30px、工具标题 17px、正文 14px、说明 12px。

布局：左对齐。侧栏容纳品牌与应用操作，主区以地块线稿介绍工作空间，下方两列工具；窄窗口改为单列但保留所有操作。工具内保持常用参数在侧栏、上传和结果在主区。

```
品牌 / 版本 | 工作台标题与运行状态
工作台      | 地块线稿与使用说明
使用提示    | 地块分析     矢量切分
日志 / 关于 | 格式转换     坐标计算
退出        | 文件处理与会话提示
```

自查：工具数量有限，不增加无意义搜索、数字统计或不可用导航；去掉重复宣传标签。用地块线稿表达 GIS 主题，其他区域保持克制。按钮有键盘焦点，状态不仅靠颜色区分；无自动动画，支持窄窗口和文字换行。
